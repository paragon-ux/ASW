# User and agent guide index

The canonical user and integration guides are now split by audience:

- [User guide](USER_GUIDE.md) — the five GUI surfaces, permissions, signals,
  subscriptions, and delivery.
- [Agent integration](AGENT_INTEGRATION.md) — the actual loopback JSON
  operations, grant intersection, cursors, revocation, and errors.

The normative semantics remain in [RFC 0001](../../asw-spec-codex/RFC-0001.md).
This index intentionally avoids duplicating the API contract.
