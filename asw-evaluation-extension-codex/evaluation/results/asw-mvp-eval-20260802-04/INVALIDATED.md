# Run invalidation

This run is retained as raw evidence but is not a valid final Phase 8 result.
Phase C review identified three audit defects after execution: integrity failures
were not folded into the final pass gate, Layer B threshold statistics used a
median of class medians instead of pooled records, and correctness/claim
reporting was not restricted to the preregistered primary classes and persisted
invalidation evidence. The frozen parameters were not tuned; a new run ID was
created after correcting aggregation, audit, and reporting semantics.
